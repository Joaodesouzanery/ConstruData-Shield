## Authorization Issues to Analyze

1. **IDOR (Insecure Direct Object References)**: Accessing other users' resources by changing IDs
2. **Horizontal Privilege Escalation**: Accessing resources of same-level users
3. **Vertical Privilege Escalation**: Accessing admin/elevated functionality as regular user
4. **Mass Assignment**: Modifying restricted fields (role, isAdmin) via API
5. **Missing Function Level Access Control**: Admin endpoints accessible without admin role
6. **Path Traversal Authorization**: Bypassing authz via path manipulation
7. **API Authorization Gaps**: Different authorization between web UI and API

## Analysis Method

For each endpoint:
1. **Identify access controls**: What authorization checks exist?
2. **Map user roles**: What roles/permissions does the app define?
3. **Find IDOR patterns**: Are resource IDs predictable/sequential?
4. **Check enforcement**: Is authorization checked server-side consistently?
