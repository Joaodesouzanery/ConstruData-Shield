## XSS Types to Analyze

1. **Reflected XSS**: User input reflected in HTTP responses without encoding
2. **Stored XSS**: User input stored and rendered to other users
3. **DOM-based XSS**: Client-side JavaScript using untrusted data in dangerous sinks
4. **Template XSS**: User input in client-side template expressions (Angular, Vue, React dangerouslySetInnerHTML)

## Analysis Method

For each potential XSS point:
1. **Identify the source**: Where does user input enter the application?
2. **Trace to output**: Where is the input rendered in HTML/JS?
3. **Check encoding**: Is output encoding applied (HTML entities, JS escaping)?
4. **Check CSP**: Does Content-Security-Policy block inline scripts?
5. **Propose payload**: What XSS payload would work given the context?
